Kaghaz Par Seedha Likhein

Koi form hai hi nahi. Screen hi invoice hai. Khali jagahein kaghaz ke andar nuqton wali lakeer hain — business ka naam wahan likhein jahan chhapega, client ka naam “Bill To” ke neeche, kaam ka naam table ki pehli line mein. Keyboard ka “next” aap ko kaghaz par aage le jata hai. Total saamne seerhi mein barhta rehta hai. Koi progress patti nahi — progress yeh hai ke kaghaz par kitni siyahi aa gayi.

Yeh file kyun mehfooz ki gayi A/B challenger

Malik ne 2026-09-25 ko teeno design default ke taur par rad kiye, magar isi ek ko alag se rakha: “ye design — kaghaz per seedha likhny wala — kaam tm apny memory per save rakhna, isko ham a/b testing zaroor kerna chain gy.” Is liye yeh default nahi, muqable ka doosra raasta hai. Poori tafseel: docs/decisions/0167.

Kharcha aur khatra: lagbhag 4–5 din. Har khana kaghaz ke andar likhna parega; jo line likhi ja rahi ho usay keyboard ke upar laana parega; bare font (1.5×) aur Urdu/Arabic (ulta rukh) ke liye apna alag imtehan chahiye.

Usool jo is design mein bhi nahi toote

  1. Koi ishtihaar nahi — kahin koi khali jagah bhi nahi chhori gayi.
  2. Koi account, koi sign-up nahi invoice ban-ne se pehle.
  3. Raqam kabhi kati nahi — zaroorat par agli line par, aur “$” apne number se kabhi juda nahi hota.
  4. Ek hi chamakta button har screen par. Total ek haqeeqat hai (halka neela), button nahi.
  5. Dark mein bhi kaghaz safed — jo aap bhej rahe hain woh safed kaghaz hai.
  6. Keyboard aage le jata hai, aur total chipki patti ke peeche kabhi nahi chhupta.
